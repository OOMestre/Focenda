# 🤝 Contributing to Focenda

Thank you for your interest in contributing to **Focenda**! 🎉

Focenda is a 100% free and open-source project built purely in Swift for the Mac community.

---

## 🛠️ How to Contribute

1. **Fork** the repository on GitHub.
2. **Create a branch** based on `staging`:
   ```bash
   git checkout -b feat/my-new-feature staging
   ```
3. **Make your changes** ensuring the code is 100% Swift/SwiftUI and follows macOS Human Interface Guidelines.
4. **Run the test suite** to ensure all tests pass:
   ```bash
   make test
   ```
5. **Commit with Conventional Commits** (`feat:`, `fix:`, `refactor:`, `test:`, `docs:`).
6. **Open a Pull Request** targeting the `staging` branch.

---

## 📋 Commit Message Convention

- `feat: add global keyboard shortcut for focus timer`
- `fix: correct countdown pause behavior`
- `refactor: optimize dashboard state observation`
- `test: add unit tests for TaskListViewModel`
- `docs: update build instructions in README`

---

Thank you for making Focenda better! 🚀
