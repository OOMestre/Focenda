## [0.1.0] - 2026-08-25

### ✨ Added
- **Initial Release of Focenda:** Native macOS productivity application.
- **Intelligent Focus Timer:** Deep focus, short breaks, and long breaks with circular progress indicator.
- **Task Management:** Add, prioritize (`High`, `Medium`, `Low`), tag, search, and check off tasks.
- **Dashboard & Analytics:** Real-time focus time aggregation and session history.
- **Modern macOS UI:** Dark and light mode support, SF Symbols, and MenuBarExtra item.
- **Automated Testing & CI/CD:** 100% test coverage for core ViewModels and GitHub Actions workflows.
- **Staging Launcher:** Easy double-click launch for local staging testing.
